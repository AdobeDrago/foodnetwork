# cards-rail

Custom **cards** block for narrow right-rail lists (What's Cooking, Recently on TV).

## Authoring (Document Authoring)

Model: `standalone`

One row per card: thumbnail cell | title link cell.

- If the last row holds only a link (e.g. "More Recipes"), it renders as a trailing
  red uppercase CTA with a teal arrow icon (editorial promo style).
- Without that row the block renders as a feed: cards get dividers, the first 4
  cards show, and a "Load More" button reveals 10 more per click.
