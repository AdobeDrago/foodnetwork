# cards-collage

Custom **cards** block. 

## Authoring (Document Authoring)

Model: `standalone`

Single block table, 3 rows x 2 columns. Each row: `4x3 image` | `H3 title linked to the gallery page`.

- Row 1 is the large feature tile (~2/3 width on desktop).
- Rows 2-3 are the smaller tiles stacked in the right 1/3 column.
- The whole tile links to the title's URL.

## Supported variations

No variations.
