Recipe Detail Pages

Migrated recipe detail pattern — dynamic JSON fill with authored content taking priority.

  • Recipe path from URL or authored recipe metadata; slugs with or without -recipe- both resolve.
  • One fetch of .sni.json powers title, rating stars, author, ingredients, directions, categories, package, show/episode.
  • Empty info/body blocks fill from JSON; authored copy always wins. Watch-promo shells no longer block fill.
  • JSON-built headings use “Ingredients:” / “Directions:”; authored headings render exactly as written.
  • Nutrition Info stays authored in a popover; one-step recipes and empty ingredient columns get source-like layout.

Dynamic recipe architecture

  • Source: foodnetwork.com .sni.json
  • Shared module: scripts/recipe-data.js
  • Path: /recipes/...(-recipe)?-<id>
  • Blocks: columns-recipe-info, columns-recipe-body
  • Images via food.fnr.sndimg.com
  • Authored content always wins
